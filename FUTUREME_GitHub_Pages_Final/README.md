# FUTUREME — Support and Privacy Website

Static GitHub Pages site with three routes:

- `/` home
- `/support/` support
- `/privacy/` privacy policy

## Publish

1. Create a public GitHub repository (for example `futureme`).
2. Upload all contents of this folder to the repository root.
3. Go to Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. After publishing, your pages will be at `https://USERNAME.github.io/futureme/support/` and `https://USERNAME.github.io/futureme/privacy/`.

Contact email: support@kook.love.

Before App Store submission, confirm that the policy reflects the exact final app, including permissions, notifications, data deletion and Apple's privacy questionnaire.
